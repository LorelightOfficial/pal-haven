A peaceful world by default.

Retaliation requires both World → Allow retaliation and the creature's own retaliation setting. Pals don't attack first. One mapped attack per creature is used for combat.

What is saved?

Worlds, creature placements, player position, health and settings save on this device. Asset blobs are stored once in the library. Export world backups before uninstalling or clearing browser/app data. Automatic save is every five seconds, on menu changes, and when leaving a world.

Which files can I import?

Creatures: .pal.zip, an embedded animated GLB, or a recovery ZIP containing exactly one GLB. Landscapes: static GLB or binary/ASCII STL. Plain GLB with embedded PNG/JPEG textures is supported; Draco, Meshopt, KTX2, cloth and arbitrary shader extensions are not. See the source documentation for exact limits.

What is Stage 2?

The separate prompt kit tells a tool-capable model how to turn your STL/OBJ/GLB into a rigged, optimized creature package that this app recognizes. This app imports completed characters; it does not generate rigs or animations from an STL.

How does terrain movement work?

Pals use a lightweight ground grid, obstacle steering and A* paths. Use single-surface outdoor terrain with gentle slopes. Multi-level buildings, caves, moving platforms, swimming, ragdolls and production physics are not part of this version.
